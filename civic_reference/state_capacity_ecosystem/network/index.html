How the affinity score is computed. For every pair of orgs we compute three signals: (1) description similarity via TF-IDF cosine over the org's description and funding-detail text; (2) segment overlap, with a primary-segment match weighted higher than secondary-segment overlap; (3) named-funder overlap, parsing funder names out of the funding-detail field. The composite is 0.4 × description + 0.35 × segments + 0.25 × funders. Edges below 0.10 are dropped, and each node is capped at ~8 strongest neighbors to prevent hairballs. What this shows: structural affinity — orgs that probably share rooms and run in similar circles. What it doesn't show: documented partnerships, deal flow, or relationship quality. Methodology developed in this conversation by Henry Tolchard.

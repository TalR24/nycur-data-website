Affinity Network

A force-directed map of which orgs are working on the same underlying problems. Type a question like "where should I work on procurement in NYC?" and the search ranks orgs by semantic relevance and highlights the top matches. Or just browse the graph: thicker edges mean the two orgs share a stronger combination of described work, problem statements, and funders. The graph deliberately under-weights segment overlap so cross-segment surprises surface.
